## 1 项目概述

本项目在 GEC6818 开发板上实现一个多页面车载中控界面。主要功能：主页六卡片、导航、仪表、音乐、相册、电话、设置、倒车；支持点击、左右滑动、左上角返回、昼夜主题和短音频播放。

当前代码、资源、构建脚本已完成，12 个 `.c` 通过语法检查；触摸和页面切换修复待上板回归。

## 3 实现功能

![](C:\Users\张浩\Pictures\Screenshots\Screenshot 2026-11-23 102232.png)

### 3.1 主页

- 3 列 × 2 行，6 张 240×150 卡片：导航、仪表、音乐、电话、相册、设置；
- 状态栏显示时间、日期、温度、音量、信号；
- 点卡片进入对应页面，左右滑动切页，右下角切换昼夜。

### 3.2 导航

- 代码绘制网格道路、路线折线、起点/终点、车辆三角；
- 显示“距目的地 3.2 km / 预计 12 分钟”；
- 点“结束导航”返回主页；
- 地图为模拟，不接 GPS。

### 3.3 仪表

- 车速表 0~240 km/h，转速表 0~8；
- 指针自动演示，数字车速同步；
- P/R/N/D 挡位、左右转向灯、油量/水温/里程；
- 点表盘开关演示，点挡位切换，点左上/右上转向灯。

### 3.4 音乐

- 专辑封面、歌名、歌手、进度条；
- 上一首、播放/暂停、下一首、音量 +/-；
- `audio=1` 调用 madplay，短音频 1/2/4 秒，播完自动下一首；
- `audio=0` 纯界面模拟，不启动子进程。

### 3.5 相册

- 扫描 `res/photo/photo_*.bmp`，按编号排序；
- 3 列 × 2 行缩略图，当前 5 张，最多 6 张；
- 点缩略图全屏；全屏左右滑动或点左/右半屏切换；
- 点右上角 × 回缩略图；左上角返回：全屏→缩略图，缩略图→主页；
- 全图 `photo_N.bmp` 800×480，缩略图 `thumb_N.bmp` 220×124，原 JPG 保留。

### 3.6 电话

- 4 个联系人卡片，选中高亮；
- 呼叫后显示“正在呼叫”，可挂断；
- 仅模拟，不真正拨号。

### 3.7 设置与倒车

- 设置：昼夜主题、亮度、音量、仪表演示开关、倒车入口；
- 倒车：全屏倒车图、绿/黄/红辅助线、R 挡提示，点击任意位置回仪表。

## 4 软件介绍

### 4.1 技术栈

| 项目 | 内容 |
| --- | --- |
| 显示 | Linux framebuffer，`/dev/fb0`，32bpp |
| 触摸 | Linux input，`/dev/input/event0` |
| 图片 | 24/32 位无压缩 BMP |
| 中文 | stb_truetype + `res/font/simfang.ttf` |
| 音频 | madplay 子进程 |
| 构建 | CMake ≥3.10 / GNU Make |
| 依赖 | 无第三方二进制库；`-lm`、`-lpthread` 为系统库 |

### 4.2 模块

| 文件 | 作用 |
| --- | --- |
| `main.c` | 入口 |
| `car.c` | 主循环、触摸分派、页面切换、开机动画 |
| `car_pages.c` | 主页/导航/仪表/音乐/相册/电话/设置/倒车 |
| `car_photo.c` | 相册扫描、缩略图、全屏、切换 |
| `car_ui.c` | 绘图原语、状态栏、提示栏 |
| `car_cfg.c` | `car.cfg` 解析 |
| `mp3.c` | madplay 播放/暂停/切歌 |
| `lcd.c` / `touch.c` | framebuffer / 触摸 |
| `bmp.c` / `text.c` / `truetype.c` | BMP / 中文 / 字库 |

### 4.3 关键实现

- LCD：`open /dev/fb0`、`FBIOGET_*`、`mmap`，按 `stride` 写 32bpp；
- 触摸：`EV_ABS` 坐标 + `BTN_TOUCH`，`EVIOCGABS` 读量程；点击阈值 60px，60~100px 小滑动按点击；
- BMP：解析文件头/信息头，行 4 字节对齐，BGR→RGB；
- 中文：字库只加载一次，UTF-8 解码，alpha 混合；
- 页面：`car_goto` 统一切换；新页面画到离屏 `next`，默认 `page_anim=0` 直接上屏；
- 相册：目录扫描、缩略图预加载、全屏图按需加载；
- 音频：`audio=1` 启动 madplay，`SIGSTOP/SIGCONT` 暂停/继续。

### 4.4 构建

```bash
# Makefile
make -j4
make pack

# CMake
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=$PWD/cmake/arm-linux-toolchain.cmake
cmake --build build -j4
```

输出：`out/carmode` / `build/bin/carmode`；部署时 `carmode` 与 `res/` 同级。

## 6 问题以及解决

| 问题 | 原因 | 处理 | 状态 |
| --- | --- | --- | --- |
| 点击图标无反应，只能滑动 | 触摸驱动先报坐标再报 `BTN_TOUCH=1`，旧代码按下时清坐标 | 按下保留坐标并 `remember_start()`；命中改用按下点；`TAP_SLOP` 24→60；60~100px 小滑动按点击；返回区 80×52 | 已改，待上板回归 |
| 页面切换闪屏 | 新页面先直接画到屏幕，再开始转场 | 新页面画到离屏 `next`；默认 `page_anim=0` 直接切换 | 已改，待上板回归 |
| 原厂 `iot` 抢占屏幕/触摸 | `/IOT` 下两个 `iot` 进程占用 fb0/event0 | `killall -9 iot`；检查 `/etc/profile`、`/etc/init.d/rcS`、`/etc/inittab` 并禁用启动项 | 已定位 |
| `make pack` 报 `file changed as we read it` | 工程在 `/mnt/hgfs` 共享目录，tar 读取时目录时间变化 | `pack` 先复制到 `/tmp/carmode_pkg` 再打包 | 已改 |

> 触摸和闪屏的最终效果以板卡回归为准；其余为代码或资源层面已处理。
